# Projeto: Decodificador em Verilog

Este repositório contém um projeto em Verilog implementado no ambiente Quartus II, com foco em um codificador e decodificador digital. O objetivo é demonstrar o funcionamento e simulação de circuitos lógicos com base em codificação e decodificação binária.

## Estrutura do Projeto

A pasta principal do projeto contém os seguintes arquivos relevantes:

### Arquivos Verilog (.v):

- `decodificador.v` — Arquivo principal com a lógica do decodificador.
- `binarios.v` — Implementa parte da codificação binária.
- `caractere.v` — Implementa os caracteres da codificação/decodificação.
- `hexadecimal_mais.v` — Módulo para manipulação hexadecimal mais significativo.
- `hexadecimal_menos.v` — Módulo para operações com hexadecimal menos significativo.
